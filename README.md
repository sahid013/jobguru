# জব গুরু — BCS Preliminary Prep

Syllabus-driven study site for the BCS preliminary exam (200 marks). Built with Next.js 16 (App Router, Cache Components) and Supabase.

Content keeps its language: Bangla subjects use Bangla text, labels and digits (৩০). English Language & Literature uses English throughout.

## Setup

```bash
npm install
npm run dev          # http://localhost:3000
```

Before Supabase is connected, the site serves the bundled syllabus in `src/data/syllabus.ts`, so you can work on the UI right away.

### Connect Supabase

1. **Keys.** In Supabase → Project Settings → API, copy the publishable (anon) key into `.env.local`:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://oaavfexootopaigidlnn.supabase.co
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<your key>
   ```
2. **Schema.** Run `supabase/migrations/0001_init.sql` in the SQL Editor.
3. **Syllabus.** Run `supabase/seed.sql` in the SQL Editor.
4. **Your account.** Restart `npm run dev`, open `/login` and create an account. Then make yourself an admin (the `/admin` page shows this SQL with your id filled in):
   ```sql
   update public.profiles set role = 'admin' where id = '<your-user-id>';
   ```

## Adding content

Go to **/admin** (the “কন্টেন্ট যোগ” link in the header):

- **New topic or sub-topic**: add one under any subject. The six subjects that have only marks so far are waiting for topics.
- **Notes**: written in Markdown (headings, lists, tables, bold), with a live preview. Save as a draft or publish.
- **MCQs**: 2–4 options, the correct answer, an explanation and a source (e.g. ৪৫তম বিসিএস).

Changes appear on the public site immediately.

## Structure

```
src/
  app/
    page.tsx                         Home — বিষয় ও পূর্ণমান table
    subjects/[subject]/              Subject: topics + book list
    subjects/[subject]/[topic]/      Topic: notes, sub-topics
      practice/                      MCQ practice
    admin/                           Editor dashboard (Server Actions in actions.ts)
    login/, auth/callback/           Supabase auth
  data/syllabus.ts                   Seed syllabus (source for seed.sql)
  lib/
    data.ts                          All public reads — cached with "use cache"
    i18n.ts                          Per-language labels + Bangla digits
    supabase/                        Browser / server / public clients
supabase/
  migrations/0001_init.sql           Tables, RLS policies, triggers
  seed.sql                           Generated by `npm run db:seed-sql`
```

## Built to scale

- **Caching.** Public pages are prerendered and cached (`cacheLife("hours")`, tag `content`). Edits call `updateTag("content")`, so readers get static pages and Supabase is barely touched.
- **Topic tree.** Topics nest to any depth through `parent_id`, so new syllabus levels need no schema change.
- **Security.** Row Level Security covers every table. Everyone can read published content; only `editor` and `admin` roles can write. Student answers go into `attempts`, ready for progress tracking later.
- **Languages.** Each subject has a `lang` column, and every page sets `lang` on its content for correct fonts and accessibility.

If you change `src/data/syllabus.ts`, run `npm run db:seed-sql` and re-run `supabase/seed.sql`. Rows are upserted by slug, so your notes and questions are kept.
